# Массивы

Массив — это последовательная коллекция элементов одного типа, расположенных в памяти друг за другом.

## Статические массивы

Размер задаётся на этапе компиляции:

```c
int numbers[5];              // массив из 5 элементов
int init[] = {1, 2, 3};     // компилятор посчитает размер
int fixed[3] = {10, 20};   // третий элемент = 0
int zeros[100] = {0};       // все элементы = 0
```

## Индексация

Индекс начинается с нуля:

```c
int arr[5] = {10, 20, 30, 40, 50};
arr[0];   // 10 (первый)
arr[4];   // 50 (последний)
// arr[5]; // 未 defined behavior — выход за границы
```

## Динамические массивы

Размер определяется в runtime:

```c
int size = getSize();
int *arr = malloc(size * sizeof(int));
// ...
free(arr);
```

## Многомерные массивы

```c
int matrix[3][4];               // 3 строки, 4 столбца
int init[2][2] = {{1, 2}, {3, 4}};

matrix[1][2] = 10;             // доступ к элементу
```

## Передача в функцию

Массив передаётся как указатель на первый элемент:

```c
void process(int arr[], int size);
void process(int *arr, int size);

// размер массива НЕ передаётся автоматически
int sum(int *arr, int n) { ... }
```

## Подводные камни

1. **Выход за границы** — неопределённое поведение
2. **Забыли freed** — утечка памяти
3. **Не передали размер** — нет проверки границ
4. **Константность** — `const int arr[]` не защищает от изменения данных
5. **Variable Length Arrays (VLA)** — размер unknown, зависит от компилятора
