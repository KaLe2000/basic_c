# Примитивные типы данных

Примитивные типы — это базовые типы данных, из которых строятся все остальные структуры. В языке C типы данных делятся на целочисленные, числа с плавающей запятой и указатели.

## Целочисленные типы (Integer Types)

### char — символьный тип
Размер: 1 байт (8 бит). Хранит код символа таблицы ASCII. Диапазон значений зависит от модификатора:
- `unsigned char`: от 0 до 255
- `signed char`: от -128 до 127

```c
char letter = 'A';          // символ 'A' имеет код 65
char digit = '7';           // символ '7', не число 7!
signed char temp = -10;    // отрицательное значение
unsigned char byte = 200;  // беззнаковое значение
```

**Подводный камень**: символ `7` и число `7` — это разные значения. Для преобразования используется `digit - '0'` или `atoi()`.

### int — целое число
Основной целочисленный тип. Стандартный размер — минимум 16 бит, но на большинстве систем это 32 бита (4 байта).

Модификаторы:
- `short int` (или `short`): минимум 16 бит
- `long int` (или `long`): минимум 32 бита
- `long long int` (или `long long`): минимум 64 бита
- `signed int` (или `signed`): знаковый (по умолчанию)
- `unsigned int` (или `unsigned`): беззнаковый

```c
int count = 100;                // обычное целое число
short year = 2024;            // 16-битное целое
long population = 8000000000; // большое число
long long bigNumber = 9223372036854775807; // 64-битное
unsigned int index = 0;        // только положительные
```

### Диапазоны значений
| Тип           | Размер     | Signed (мин — макс)              | Unsigned (макс) |
|---------------|-----------|----------------------------------|----------------|
| char          | 1 байт    | -128 … 127                       | 255            |
| short         | 2 байта    | -32 768 … 32 767                 | 65 535         |
| int           | 4 байта    | -2 147 483 648 … 2 147 483 647  | 4 294 967 295  |
| long          | 4/8 байт   | зависит от платформы             | зависит        |
| long long     | 8 байт     | -9.2·10¹⁸ … 9.2·10¹⁸           | 1.8·10¹⁹      |

## Типы с плавающей запятой (Floating-Point Types)

### float — число одинарной точности
Размер: 4 байта (32 бита). Точность: 6-7 десятичных цифр.

```c
float pi = 3.14159f;      // суффикс f обязателен для литералов
float e = 2.71828f;
float price = 19.99f;
```

### double — число двойной точности
Размер: 8 байт (64 бита). Точность: 15-16 десятичных цифр. Используется по умолчанию для вещественных литералов.

```c
double gravity = 9.80665;       // без суффикса — это double
long double precise = 3.14159265358979323846L; // расширенная точность
```

### IEEE 754 Standard
| Тип    | Биты | Знак | Экспонента | Мантисса | Точность      |
|--------|------|------|-----------|----------|--------------|
| float  | 32   | 1    | 8         | 23       | 6-7 цифр     |
| double | 64   | 1    | 11        | 52       | 15-16 цифр    |

**Подводный камень**: сравнение чисел с плавающей запятой через `==` может давать неожиданные результаты из-за погрешности представления.

```c
// НЕПРАВИЛЬНО
if (0.1f + 0.2f == 0.3f) { } // false!

// ПРАВИЛЬНО — сравнение с погрешностью
float diff = fabs((0.1f + 0.2f) - 0.3f);
if (diff < 0.0001f) { }
```

## Специальные типы

### size_t — беззнаковый тип для размеров
Предназначен для хранения размеров объектов в памяти. Размер зависит от архитектуры:
- 32-битные системы: 32 бита
- 64-битные системы: 64 бита

```c
size_t arraySize = 100;
size_t stringLength = strlen(str);
```

**Подводный камень**: при выводе через printf используется спецификатор `%zu`, а не `%d` или `%lu`.

```c
size_t len = 100;
printf("Length: %zu\n", len); // правильно
```

### ptrdiff_t — разность указателей
Тип для хранения разности двух указателей.

```c
ptrdiff_t diff = ptr2 - ptr1;
```

### intptr_t / uintptr_t — указатели как целые числа
Типы для безопасного преобразования указателей в целые числа и обратно.

## Символьные константы

### escape-последовательности
```c
'\n'   // перевод строки (ASCII 10)
'\t'   // табуляция (ASCII 9)
'\r'   // возврат каретки (ASCII 13)
'\\'   // обратный слэш
'\''   // одинарная кавычка
'\"'   // двойная кавычка
'\0'   // нуль-символ (константа для строк)
'\xFF' // шестнадцатеричный код символа
```

## Преобразование типов (Type Casting)

### Явное преобразование
```c
int a = 10;
int b = 3;
double result = (double)a / b;  // 3.333..., а не 3
```

### Неявное преобразование
```c
int i = 100;
long long ll = i;  // автоматическое расширение
```

### Правила неявного преобразования
1. `char` и `short` расширяются до `int`
2. Если один операнд `long long`, другой приводится к `long long`
3. Если один `double`, другой приводится к `double`
4. При присваивании правый операнд приводится к типу левого

## Стандартные константы (limits.h)

```c
#include <limits.h>

INT_MIN    // минимальное значение int
INT_MAX    // максимальное значение int
UINT_MAX   // максимальное unsigned int
CHAR_MIN   // минимальное char
CHAR_MAX   // максимальное char
LONG_MIN   // минимальное long
LONG_MAX   // максимальное long
LLONG_MIN  // минимальное long long
LLONG_MAX  // максимальное long long
```

## Стандартные константы (float.h)

```c
#include <float.h>

FLT_MAX     // максимальное float
FLT_MIN     // минимальное положительное float
DBL_MAX     // максимальное double
DBL_MIN     // минимальное положительное double
FLT_EPSILON // машинная точность (float)
DBL_EPSILON // машинная точность (double)
```

## Размеры типов

Для определения размера типа используется оператор `sizeof`:

```c
#include <stdio.h>

printf("char:       %zu байт\n", sizeof(char));
printf("int:        %zu байт\n", sizeof(int));
printf("long:       %zu байт\n", sizeof(long));
printf("long long:  %zu байт\n", sizeof(long long));
printf("float:      %zu байт\n", sizeof(float));
printf("double:     %zu байт\n", sizeof(double));
printf("size_t:     %zu байт\n", sizeof(size_t));
```
