# Строки

В языке C строка — это массив символов, завершающийся нуль-символом `'\0'`.

## Объявление и инициализация

```c
char s1[] = "Hello";           // {'H','e','l','l','o','\0'}
char s2[6] = "Hello";         // тот же результат
char s3[10] = "Hello";       // лишние символы = '\0'
char *s4 = "Hello";          // указатель на строковый литерал
char s5[] = {'H','e','l','l','o','\0'}; // ручное заполнение
```

## Ввод и вывод

```c
#include <stdio.h>

char name[100];
scanf("%99s", name);              // читает до пробела
fgets(name, 100, stdin);         // читает всю строку с пробелами

printf("%s\n", name);            // вывод строки
puts(name);                      // вывод + перевод строки
```

## Строковые функции (string.h)

### Длина строки
```c
size_t len = strlen(s);  // без учёта '\0'
```

### Копирование
```c
strcpy(dest, src);              // без проверки размера
strncpy(dest, src, n);        // копирует n символов
// подводный камень: не добавляет '\0' если src >= n
strncpy(dest, src, n - 1);
dest[n - 1] = '\0';
```

### Конкатенация
```c
strcat(dest, src);             // добавляет src в конец dest
strncat(dest, src, n);        // добавляет не более n символов
// подводный камень: dest должен иметь достаточно места
```

### Сравнение
```c
strcmp(s1, s2);               // 0 если равны
strncmp(s1, s2, n);           // сравнение первых n символов
// возвращает: <0, 0, >0
```

### Поиск
```c
char *p = strchr(s, 'c');     // первое вхождение символа
char *p = strstr(s, "sub");   // первое вхождение подстроки
```

### Другие функции
```c
memset(s, 0, len);            // заполнение нулями
memcpy(dest, src, n);          // копирование n байт
memmove(dest, src, n);        // безопасное копирование (оверлап)
```

## Преобразования

```c
#include <stdlib.h>

int i = atoi("123");           // строка → int
long l = atol("12345");       // строка → long
int i = atoi("10.5");       // = 10 (прекращает на точке)
double d = atof("3.14");      // строка → double
```

### Безопасное преобразование
```c
char *end;
long l = strtol("  42abc", &end, 10);
// end указывает на первый не преобразованный символ
// пропускает пробелы
//基底 10 = десятичная система
```

## Подводные камни

### 1. Отсутствие границ
```c
char buf[5];
strcpy(buf, "Hello");  // 未 defined behavior
```

### 2. Не добавили '\0'
```c
strncpy(buf, "Hello", 5);  // 可能 не будет '\0'
```

### 3. scanf читает только до пробела
```c
scanf("%s", name);  // "John Doe" → только "John"
```

### 4. Перекрытие буферов
```c
strcpy(s + 1, s);  // 未 undefined: источник и назначение перекрываются
```

### 5. atoi без проверки ошибок
```c
atoi("abc");  // возвращает 0, непонятно — ошибка или "0"
```

## Форматирование

```c
#include <stdio.h>

sprintf(buf, "%s %d", "Value:", 42);     // форматированный вывод
snprintf(buf, size, "%s %d", "Value:", 42); // безопасная версия
```
