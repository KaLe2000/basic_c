# Указатели

Указатель — это переменная, хранящая адрес другой переменной в памяти.

## Основы

```c
int value = 42;
int *ptr = &value;     // & — взятие адреса
*ptr = 100;           // * — разыменование (доступ к значению)

printf("%d", *ptr);   // 100
printf("%p", ptr);    // адрес в памяти
```

## Объявление

```c
int *p1;      // указатель на int
int* p2;      // тот же смысл (стиль)
int * p3;     // тот же смысл (стиль)
```

**Подводный камень**: стиль `int* p` может вводить в заблуждение:
```c
int* p1, p2;  // p1 — указатель, p2 — обычная переменная!
int *p1, *p2;   // оба указателя (стиль на каждой строке)
```

## Операции с указателями

### Взятие адреса (&)
```c
int x = 10;
int *ptr = &x;  // ptr хранит адрес x
```

### Разыменование (*)
```c
int x = 10;
int *ptr = &x;
printf("%d", *ptr);  // 10 (значение по адресу)
*ptr = 20;           // изменяем значение x
```

## Арифметика указателей

Указатель смещается на размер типа:

```c
int arr[] = {10, 20, 30};
int *p = arr;

p[0];     // 10
p[1];     // 20
*(p + 1); // 20 (то же самое)

p++;      // сдвиг на sizeof(int) байт
```

### Допустимые операции
```c
ptr + n      // сложение с числом
ptr - n      // вычитание числа
ptr1 - ptr2  // разность указателей (ptrdiff_t)
ptr++ / ++ptr / ptr-- / --ptr  // инкремент/декремент
```

### Недопустимые операции
```c
ptr1 + ptr2  // запрещено
ptr * n      // запрещено
ptr / n      // запрещено
```

## Указатель void (void*)

Обобщённый указатель. Не может быть разыменован напрямую:

```c
void *ptr = malloc(sizeof(int));
int *ip = (int*)ptr;  // требуется приведение

// можно сравнивать, но нельзя:
// *ptr = 10;  // ошибка
```

## Указатель на указатель

```c
int value = 10;
int *ptr = &value;
int **pptr = &ptr;   // указатель на указатель

**pptr = 20;         // изменяем value через два уровня
```

**Применение**: для изменения указателя внутри функции:

```c
void allocArray(int **ptr, size_t size) {
    *ptr = malloc(size * sizeof(int));
}

int *arr = NULL;
allocArray(&arr, 10);  // передаём адрес указателя
```

## Указатели и массивы

Массив как параметр функции — это указатель на первый элемент:

```c
int arr[5] = {1, 2, 3, 4, 5};
int *p = arr;   // эквивалентно &arr[0]

p[0];         // 1 (то же что arr[0])
*(p + 2);    // 3 (то же что arr[2])
```

**Подводный камень**: sizeof не работает как ожидаешь:
```c
void func(int arr[]) {
    sizeof(arr);  // размер указателя, не массива!
}
```

## Указатель NULL

```c
int *ptr = NULL;  // "никуда не указывает"

// проверка перед использованием
if (ptr != NULL) {
    // безопасно
}

// освобождение
free(ptr);
ptr = NULL;  // защита от двойного освобождения
```

## Функции и указатели

### Передача по указателю (аналог ссылок)
```c
void swap(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

int x = 1, y = 2;
swap(&x, &y);  // теперь x=2, y=1
```

### Возврат указателя
```c
int* findMax(int *arr, size_t n) {
    int *max = arr;
    for (size_t i = 1; i < n; i++) {
        if (*max < arr[i]) {
            max = &arr[i];
        }
    }
    return max;  // возвращаем адрес
}
```

**Подводный камень**: не возвращай указатель на локальную переменную:
```c
int* badFunc() {
    int local = 10;
    return &local;  // UB: локальная переменная уничтожена
}
```

## Константные указатели

| Объявление | Что константа | Можно изменить |
|------------|--------------|----------------|
| `const int *p` | данные | адрес |
| `int *const p` | адрес | данные |
| `const int *const p` | оба | ничего |

```c
const int x = 10;
const int *ptr = &x;  // нельзя *ptr = 20

int arr[3] = {1, 2, 3};
int *const p = arr;    // нельзя p = arr + 1
```

## Подводные камни

### 1. Неинициализированный указатель
```c
int *ptr;     // мусорный адрес!
*ptr = 10;   // UB: запись в случайную память
```

### 2. Использование после free
```c
int *ptr = malloc(sizeof(int));
free(ptr);
*ptr = 10;   // UB: использование освобождённой памяти
```

### 3. Выход за границы массива
```c
int arr[3];
int *p = arr;
*(p + 100) = 10;  // UB: запись за пределами массива
```

### 4. Разность указателей разных массивов
```c
int arr1[3], arr2[3];
int *p1 = arr1, *p2 = arr2;
ptrdiff_t diff = p2 - p1;  // UB (не связаны логически)
```

### 5. Приведение типов без понимания
```c
double d = 3.14;
int *p = (int*)&d;  // UB: неправильный доступ
```

## Указатели на функции

```c
int add(int a, int b) { return a + b; }

int (*funcPtr)(int, int) = add;  // указатель на функцию
int result = funcPtr(2, 3);       // вызов через указатель
```

**Применение**: callbacks, таблицы диспетчеризации:

```c
typedef int (*Operation)(int, int);

int execute(Operation op, int a, int b) {
    return op(a, b);
}
```

## Указатель и структуры

```c
struct Node {
    int value;
    struct Node *next;
};

struct Node node = {10, NULL};
struct Node *p = &node;
p->value;        // то же что (*p).value
p->next;        // доступ к полю next
```
